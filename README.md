**Streamable Dark Mode:** a dark theme for [streamable.com](https://streamable.com).

## Install

1. Install [Stylus](https://add0n.com/stylus.html) for Firefox or Chrome.
2. Open [streamable-dark.user.css](https://raw.githubusercontent.com/OD728/StreamableDark/main/streamable-dark.user.css) and click **Install style**.

Stylus checks this link for updates.

## What it does

- Switches Streamable's own theme colours (`--loop-*` variables) to dark, so the page background, titles, view count and footer turn dark together.
- Dark top bar with a white logo.
- Dark Share button and readable footer links.
- Dark scrollbar in Firefox and Chrome.
- Leaves the video player alone, since it is already dark.
